# Guión de Sustentación / Demostración (5 a 7 Minutos)
 
1. **Introducción (1 min):** Presentación del equipo y arquitectura basada en Vanilla JS + Módulos ES sin frameworks.
2. **Autenticación y Roles (2 min):** Inicio de sesión con usuario `admin`, revisión del enrutador por hash y protección de rutas. Cierre e inicio con rol `vendedor`.
3. **Módulo de Almacén y Matemáticas (2 min):** Creación y eliminación de productos, cálculo de variaciones porcentuales de KPIs e impuestos.
4. **Conclusión (1 min):** Explicación del desacoplamiento de servicios async preparados para consumo de API REST futuro.
